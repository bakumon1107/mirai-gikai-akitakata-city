# 一般質問機能 fukuoka形式移行設計書

**作成日**: 2026-05-08  
**対象リポジトリ**: mirai-gikai-akitakata-city  
**ブランチ**: akitakata/feat/gq-format  

---

## 背景・目的

安芸高田市版の一般質問機能は独自形式（LINEチャットUI・レーダーチャート・スタンス分析）で実装されていた。  
mirai-gikai-fukuoka-city 版で採用された**テーマ別市民向けビュー**に統一する。

---

## 変更方針

### 廃止する機能
| 廃止対象 | 理由 |
|---|---|
| LINE風チャットUI（交換記録形式） | fukuoka形式ではチャット形式のサマリーUIに統一 |
| レーダーチャート（5軸評価） | 評価系UIを廃止しコンテンツ優先の設計に |
| スタンス分析テキスト | 廃止 |
| `questioner_stance` カラム | 不要 |
| `stance_analysis` カラム | 不要 |
| `radar_scores` カラム | 不要 |
| `overall_summary` カラム | `summary` に統一 |
| `pdf_url` カラム | `source_url` に統一 |

### 導入する機能（fukuoka形式）
| 機能 | 説明 |
|---|---|
| テーマ別一覧ビュー | `SessionTopicsView` — 8カテゴリのカードグリッド |
| チャット形式サマリー | `QuestionChatView` — Q/A のチャットバブル |
| 原文/要約トグル | `QuestionViewToggle` — raw_text がある場合に切り替えボタンを表示 |
| カテゴリ自動分類 | `buildTopicGroups()` — トピックタイトルのキーワードで8カテゴリに振り分け |
| トップページバナー | `GeneralQuestionsBanner` — 最新公開セッションへリンク |

## DBスキーマ変更

### 削除カラム
```sql
ALTER TABLE general_questions
  DROP COLUMN pdf_url,
  DROP COLUMN overall_summary,
  DROP COLUMN questioner_stance,
  DROP COLUMN stance_analysis,
  DROP COLUMN radar_scores;
```

### 追加カラム
```sql
ALTER TABLE general_questions
  ADD COLUMN questioner_party text,
  ADD COLUMN question_order int NOT NULL DEFAULT 1,
  ADD COLUMN summary text,
  ADD COLUMN raw_text text,
  ADD COLUMN source_url text,
  ADD COLUMN publish_status text NOT NULL DEFAULT 'draft'
    CHECK (publish_status IN ('draft', 'published'));
```

### `topics` JSONB 構造の変更

**旧形式（akitakata独自）**:
```json
[{
  "index": 1,
  "title": "子育て支援の充実について",
  "question_summary": "...",
  "answer_summary": "...",
  "exchanges": [
    { "speaker": "questioner", "name": "議員名", "text": "..." },
    { "speaker": "answerer", "name": "局長名", "role": "局長", "text": "..." }
  ]
}]
```

**新形式（fukuoka互換）**:
```json
[{
  "title": "子育て支援の充実について",
  "question_summary": "市の子育て支援の現状と今後の方針は？",
  "answer_summary": "令和9年度から第3子以降の保育料無償化を拡充する。",
  "answerer_role": "市民生活部長",
  "answerer_name": "田中太郎",
  "block_summary": null
}]
```

## ページ構成

### `/sessions/[slug]/questions`
- セッション内の一般質問をテーマ別に表示
- `SessionTopicsView` で8カテゴリのカードグリッドを描画
- 各カードから `/questions/[id]` へ遷移

### `/questions/[id]`
- 個別議員の一般質問詳細
- `raw_text` と `topics` 両方ある場合 → `QuestionViewToggle`（要約/原文切り替え）
- `topics` のみ → `QuestionChatView`
- `raw_text` のみ → `RawTranscriptView`

### `/questions`（リダイレクト）
- activeSession の `/sessions/[slug]/questions` へリダイレクト

## データ移行

既存の `general_questions` データ（旧形式の `topics` JSONB）は新形式と互換性がない。  
移行後は `packages/seed/akitakata/seed-general-questions.ts` を fukuoka 形式のデータ構造で再作成すること。

## 検証方法

1. `/sessions/[slug]/questions` でカテゴリ別カードグリッドが表示される
2. 各カードの「質疑の詳細→」をクリックして `/questions/[id]` へ遷移できる
3. `topics` と `raw_text` 両方あるケース：「要約」「詳しく（原文）」トグルが表示される
4. `topics` のみのケース：チャット形式サマリーが表示される
5. トップページに一般質問バナーが表示される（publishedデータがある場合）
6. `pnpm lint` と `pnpm typecheck` が通る
