# 別地域向け Fork 手順書

> このガイドは、川崎市議会版（みらい議会ー川崎版）の作成者が別の地方議会向けに Fork する際の手順をまとめたものです。

---

## 1. はじめに

本リポジトリはオープンソースで公開されており、他の地方議会向けにカスタマイズして利用できます。
川崎市固有の情報は `site.config.ts` に集約されているため、**最小限の変更でForkが可能**です。

---

## 2. 最低限変更が必要なファイル

### 2-1. `web/src/config/site.config.ts` ← **最重要・ここだけ変えればほぼ動く**

```typescript
export const siteConfig = {
  siteName: "みらい議会ーXX版",          // ← サイト名を変更
  siteDescription: "XX市議会で今どんな議案が検討されているか...",  // ← 説明を変更
  cityName: "XX市",                       // ← 市区町村名を変更
  councilName: "XX市議会",               // ← 議会名を変更
  keywords: ["みらい議会ーXX版", "議案", "XX市", ...],  // ← キーワードを変更
  councilBaseUrl: "https://www.city.xx.jp/",             // ← 議会サイトのベースURLを変更
  councilBillsDetailUrl: "https://www.city.xx.jp/...",   // ← 議案・議決結果一覧URLを変更
  twitterHashtag: "みらい議会XX版",      // ← Xのハッシュタグを変更（#なし）
  externalLinks: {
    report: "https://forms.gle/...",       // ← 問題報告フォームURLを変更
    aboutNote: "https://note.com/...",     // ← サービス説明noteのURLを変更
    donation: "https://team-mir.ai/support/donation",  // ← 変更不要（チームみらい共通）
    teamAbout: "https://team-mir.ai/about",            // ← 変更不要（チームみらい共通）
    terms: "https://team-mir.ai/terms",                // ← 変更不要（チームみらい共通）
    privacy: "https://team-mir.ai/privacy",            // ← 変更不要（チームみらい共通）
    faq: "https://team-mirai.notion.site/FAQ-...",     // ← 変更不要（チームみらい共通）
  },
} as const;
```

## 4. 環境変数の設定

`.env.example` を `.env` にコピーして値を設定してください。

```bash
cp .env.example .env
```

主要な設定項目：

| 変数名 | 説明 | 必須 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | SupabaseプロジェクトURL | ✅ |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase匿名キー | ✅ |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabaseサービスロールキー | ✅ |
| `SUPABASE_URL` | Supabase URL（サーバーサイド用） | ✅ |
| `REVALIDATE_SECRET` | Web側キャッシュ無効化用シークレットキー | ✅ |
| `AI_GATEWAY_API_KEY` | Vercel AI GatewayのAPIキー（AIチャット・インタビュー機能に必要） | ✅ |
| `NEXT_PUBLIC_WEB_URL` | 公開WebアプリのURL | ✅ |
| `ADMIN_URL` | AdminサーバーのURL | ✅ |
| `OPENAI_API_KEY` | OpenAI APIキー（DALL-Eによる議案サムネイル画像の自動生成に使用） | ✅ |
| `DALLE_MODEL` | DALL-Eモデル選択（`dall-e-2` または `dall-e-3`、省略時は `dall-e-3`） | 任意 |
| `LANGFUSE_PUBLIC_KEY` | Langfuse公開キー（プロンプト管理・LLM監視） | ✅ |
| `LANGFUSE_SECRET_KEY` | Langfuseシークレットキー | ✅ |
| `LANGFUSE_BASE_URL` | LangfuseベースURL（デフォルト: `https://cloud.langfuse.com`） | ✅ |
| `CHAT_DAILY_USER_COST_LIMIT_USD` | AIチャット日次コストリミット（USD）- ユーザー単位 | 任意 |
| `CHAT_DAILY_TOTAL_COST_LIMIT_USD` | AIチャット日次コストリミット（USD）- システム全体 | 任意 |
| `CHAT_MONTHLY_TOTAL_COST_LIMIT_USD` | AIチャット月間コストリミット（USD）- システム全体 | 任意 |
| `CLAUDE_CLI_PATH` | AI情報収集で使用するClaude CLIのパス（省略時はPATH上の `claude`） | 任意 |
| `BASIC_AUTH_USER` / `BASIC_AUTH_PASSWORD` | Basic認証（ステージング環境等で利用） | 任意 |
| `WEB_PORT` / `ADMIN_PORT` | devサーバーのポート番号（デフォルト: 3002 / 3001）。複数のmirai-gikai系プロジェクトを同時起動する場合に変更 | 任意 |
| `NEXT_PUBLIC_GA_TRACKING_ID` | Google Analytics ID | 任意 |

### 4-1. OpenAI API キーの取得

議案サムネイル画像の自動生成（DALL-E）に OpenAI API キーが必要です。

1. [OpenAI Platform](https://platform.openai.com/) でアカウントを作成
2. API Keys ページで新しいキーを発行
3. `.env` の `OPENAI_API_KEY` に設定
4. DALL-E の利用には OpenAI アカウントへのクレジット追加（従量課金）が必要です

## 5. Supabase・DBセットアップ手順

```bash
# ローカルSupabaseの起動
npx supabase start

# マイグレーションの適用
pnpm db:migrate

# 型定義の生成
pnpm db:types:gen

# シードデータの投入
pnpm seed
```

詳細は `docs/kawasaki/20260219_1000_ローカル環境起動手順.md` を参照してください。

---

## 6. Langfuse プロンプト設定

AIチャット・インタビュー機能では Langfuse でプロンプトを管理しています。

1. Langfuse のプロジェクトを作成し、環境変数を設定
2. 以下のプロンプトを議会・地域情報に合わせて更新：
   - AIチャット用プロンプト
   - AIインタビュー用プロンプト
3. 更新後は管理画面で動作確認
