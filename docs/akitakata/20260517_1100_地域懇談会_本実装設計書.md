## 5. DBスキーマ

```sql
-- 懇談会（年度）マスタ
create table community_consultations (
  id                   uuid primary key default gen_random_uuid(),
  fiscal_year          text not null unique,   -- 'r7'（ルーティングキー）
  fiscal_year_label    text not null,           -- '令和7年度'
  title                text not null,
  pdf_url              text,
  status               text default 'published',
  held_from            date,
  held_to              date,
  total_participants   integer,
  total_opinions       integer,
  ai_year_summary      text,                   -- 年度一覧カードの一行まとめ
  ai_issue_cards       jsonb,                  -- 課題カード（JSON配列）
  created_at           timestamptz default now()
);
alter table community_consultations enable row level security;

-- 開催記録（会場ごと）
create table community_consultation_meetings (
  id                        uuid primary key default gen_random_uuid(),
  consultation_id           uuid references community_consultations(id) on delete cascade,
  location_name             text not null,
  held_at                   date,
  participant_count         integer,
  theme                     text,
  ai_representative_quote   text              -- 会場カードに使う代表引用
);
alter table community_consultation_meetings enable row level security;

-- 意見
create table community_consultation_opinions (
  id                    uuid primary key default gen_random_uuid(),
  consultation_id       uuid references community_consultations(id) on delete cascade,
  department            text not null,
  opinion_number        integer,
  text                  text not null,
  is_cross_department   boolean default false,
  opinion_type          text,                 -- demand / proposal / complaint / question
  ai_summary            text,
  created_at            timestamptz default now()
);
alter table community_consultation_opinions enable row level security;

-- AIタグ
create table community_consultation_opinion_tags (
  opinion_id   uuid references community_consultation_opinions(id) on delete cascade,
  tag          text not null,
  primary key (opinion_id, tag)
);
alter table community_consultation_opinion_tags enable row level security;
```

## 7. seed スクリプト

```
packages/seed/akitakata/
  seed-community-consultations.ts     # 懇談会マスタ・会場・意見を投入
  generate-consultation-ai.ts         # Claude API で ai_* カラムを生成
  download-consultation-pdf.sh        # PDF ダウンロード
  parse-consultation-pdf.py           # pdftotext → 意見ごとに分割
```

### generate-consultation-ai の処理フロー

```
1. 全意見テキストを部署・番号つきで読み込む
2. Claude API に 1意見ずつ投げる:
   → opinion_type / ai_summary / tags を生成
3. 全意見まとめて投げる（1リクエスト）:
   → ai_issue_cards（課題カード 6件）を生成
4. 会場ごとの意見を投げる:
   → ai_representative_quote を生成
5. 年度全体まとめを生成:
   → ai_year_summary（一覧カード用の1文）
```

## 9. 論点

| # | 論点 | 方針 |
|---|------|------|
| 1 | **市長記者会見アーカイブ** | ラジオに含める。現行の `PressConferenceArchiveSection` を `ArchivePressConferencesTab` に切り出してラジオ内に統合 |
| 2 | **`/community-consultations/latest` の「最新」定義** | `status='published'` かつ `held_from` が最新のもの |
| 3 | **一般質問アーカイブ** のローダー | `council_sessions` テーブルに questions のカウントを JOIN するか、別に query するか。JOIN推奨 |
| 4 | **ラジオボタンの初期選択** | `議案一覧` をデフォルト（現行と同じ挙動） |
| 5 | **地域懇談会 意見の全文公開** | PDF 原文ベースのため問題ない想定。要最終確認 |
