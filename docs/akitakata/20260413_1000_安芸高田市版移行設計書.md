## 4. 環境変数の設定一覧

`.env.example` を `.env` にコピーして各値を設定してください。

```bash
cp .env.example .env
```

| 変数名 | 用途 | 必須/任意 | 備考 |
|---|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | SupabaseプロジェクトURL | ✅ 必須 | 安芸高田市版専用のSupabaseプロジェクトを作成して設定 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase匿名キー | ✅ 必須 | 同上 |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabaseサービスロールキー | ✅ 必須 | 同上 |
| `SUPABASE_URL` | Supabase URL（サーバーサイド用） | ✅ 必須 | 通常は `NEXT_PUBLIC_SUPABASE_URL` と同値 |
| `REVALIDATE_SECRET` | Webキャッシュ無効化用シークレットキー | ✅ 必須 | ランダムな文字列を生成して設定 |
| `AI_GATEWAY_API_KEY` | Vercel AI GatewayのAPIキー | ✅ 必須 | AIチャット機能に必要 |
| `NEXT_PUBLIC_WEB_URL` | 公開WebアプリのURL | ✅ 必須 | 例: `https://akitakata.mirai-gikai.example.com` |
| `ADMIN_URL` | AdminサーバーのURL | ✅ 必須 | 例: `https://admin.akitakata.mirai-gikai.example.com` |
| `OPENAI_API_KEY` | OpenAI APIキー（DALL-E画像生成） | ✅ 必須 | 議案サムネイル自動生成に使用 |
| `DALLE_MODEL` | DALL-Eモデル選択 | 任意 | `dall-e-2` または `dall-e-3`（省略時は `dall-e-3`） |
| `LANGFUSE_PUBLIC_KEY` | Langfuse公開キー | ✅ 必須 | プロンプト管理・LLM監視 |
| `LANGFUSE_SECRET_KEY` | Langfuseシークレットキー | ✅ 必須 | 同上 |
| `LANGFUSE_BASE_URL` | LangfuseベースURL | ✅ 必須 | デフォルト: `https://cloud.langfuse.com` |
| `CHAT_DAILY_USER_COST_LIMIT_USD` | AIチャット日次コストリミット（ユーザー単位） | 任意 | 設定しない場合は制限なし |
| `CHAT_DAILY_TOTAL_COST_LIMIT_USD` | AIチャット日次コストリミット（システム全体） | 任意 | 同上 |
| `CHAT_MONTHLY_TOTAL_COST_LIMIT_USD` | AIチャット月間コストリミット（システム全体） | 任意 | 同上 |
| `CLAUDE_CLI_PATH` | AI情報収集で使用するClaude CLIのパス | 任意 | 省略時はPATH上の `claude` を使用 |
| `BASIC_AUTH_USER` / `BASIC_AUTH_PASSWORD` | Basic認証（ステージング環境用） | 任意 | 公開前の確認環境で設定を推奨 |
| `WEB_PORT` / `ADMIN_PORT` | devサーバーのポート番号 | 任意 | 他のmirai-gikaiプロジェクトと同時起動する場合に変更（デフォルト: 3002/3001） |
| `NEXT_PUBLIC_GA_TRACKING_ID` | Google Analytics ID | 任意 | アクセス解析を行う場合に設定 |
