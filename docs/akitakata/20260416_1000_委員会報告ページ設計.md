# 委員会報告ページ 設計書

作成日: 2026-04-16

## 概要

安芸高田市議会の「所管事務調査報告書」を一覧・閲覧できるページ。
参照元: https://www.akitakata.jp/ja/parliament/q475/

---

## データ構造

### ソース

市公式サイトの「委員会報告」ページに掲載されている PDF リンクを取得。
常任委員会が所管事務の調査を終了するたびに報告書が公開される。

### 報告書の種別

| 委員会 | 説明 |
|---|---|
| 総務文教常任委員会 | 行財政・教育・交通等を所管 |
| 産業厚生常任委員会 | 産業振興・福祉・農業等を所管 |
| 議会改革特別委員会 | 議員定数・報酬・議会改革を担当 |

### DB テーブル設計案: `committee_reports`

```sql
create table committee_reports (
  id uuid primary key default gen_random_uuid(),
  council_session_id uuid references council_sessions(id) on delete set null,
  committee_name text not null,  -- 例: "総務文教常任委員会"
  title text not null,           -- 調査項目名
  report_date date not null,     -- 報告日
  pdf_url text,                  -- 報告書 PDF の URL
  attachment_urls text[],        -- 別紙など複数ファイル
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
alter table committee_reports enable row level security;
create index committee_reports_report_date_idx on committee_reports(report_date desc);
```

## ページ構成

### URL

`/committee-reports`

### ページタイトル

「委員会報告」

### レイアウト

```
[ ページタイトル：委員会報告 ]
[ 説明文: 常任委員会が所管事務調査を終了した結果を報告します。 ]

[ 委員会タブ or セクション ]
  ┌─ 全て ─ 総務文教 ─ 産業厚生 ─ 議会改革 ─┐

[ 年月の降順リスト ]
  ┌────────────────────────────────────────┐
  │ [委員会バッジ] [報告日] YYYY.M.D        │
  │ タイトル（調査項目名）                   │
  │ [ 報告書を見る ↗ ]                      │
  └────────────────────────────────────────┘
  …
```

### カードコンポーネント

- 委員会名バッジ（色分け）
  - 総務文教: `bg-blue-100 text-blue-700`
  - 産業厚生: `bg-green-100 text-green-700`
  - 議会改革: `bg-purple-100 text-purple-700`
- 報告日（YYYY.M.D 形式）
- 調査項目タイトル（最大 2 行クランプ）
- 「報告書を見る」ボタン → PDF を別タブで開く
- 別紙がある場合は「別紙」ボタンも表示

### ソート順

`report_date DESC`（新しい報告が上）

### フィルタ

委員会名でタブ切り替え（URL クエリ: `?committee=総務文教` など）
