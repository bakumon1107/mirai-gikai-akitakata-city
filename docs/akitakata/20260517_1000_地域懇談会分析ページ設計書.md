# 地域懇談会 分析ページ 設計書

作成日: 2026-05-17

---

## 1. 概要・目的

安芸高田市議会が毎年度実施する「地域懇談会」の住民意見を、検索・フィルタ・可視化できる形でWebに公開する。

**現状の課題**
- 意見はPDF一枚に400件以上が羅列されており、市民・議員ともに「何が多く言われているか」を俯瞰できない
- 年度をまたいで同じ課題が繰り返されているかどうかも分からない
- 地域ごとの温度差も見えにくい

**期待効果**
- 住民：自分たちの声がどう整理されたかを確認できる
- 議員：テーマ別・地域別に意見を横断的に参照し、政策立案に活用できる
- メディア：件数や傾向をデータとして使える

## 2. PDFの構造（令和7年度版で確認）

```
開催概要
  - 6会場（八千代/甲田/向原/美土里/高宮/吉田）
  - 参加者合計: 99人

意見集（部署別）
  - 危機管理監関係:   14件
  - 総務部関係:       35件
  - 企画部関係:       86件  ← 最多
  - 市民部関係:       20件
  - 福祉保健部関係:   21件
  - 産業部関係:       49件
  - 建設部関係:       29件
  - 教育委員会関係:   40件
  - 行政委員会関係:   38件
  - 市全体に対して:    6件
  - 議会関係:         60件
  - 国・県関係:       ~11件
  合計: 400件以上

特記
  - 「網掛け」意見 = 複数部署に関わる意見（各部署に重複掲載）
  - 後半に「提案型」意見あり（課題+提案の箇条書き形式）
  - 会場ごとのテーマ: フリーテーマ／地域コミュニティ／振興会活動／空き家と駅周辺
```

## 3. DBスキーマ

### 3-1. テーブル定義

```sql
-- 懇談会（年度）マスタ
create table community_consultations (
  id            uuid primary key default gen_random_uuid(),
  fiscal_year   text not null,        -- '令和7年度'
  title         text not null,        -- '令和7年度 地域懇談会'
  pdf_url       text,
  status        text default 'published',
  held_from     date,                 -- 2025-07-23
  held_to       date,                 -- 2025-08-07
  total_participants integer,
  created_at    timestamptz default now()
);

-- 開催記録（会場ごと）
create table community_consultation_meetings (
  id                      uuid primary key default gen_random_uuid(),
  consultation_id         uuid references community_consultations(id) on delete cascade,
  location_name           text not null,  -- '八千代町'
  held_at                 date,
  participant_count       integer,
  theme                   text            -- 'フリーテーマ' / '地域コミュニティについて' etc.
);

-- 意見
create table community_consultation_opinions (
  id                      uuid primary key default gen_random_uuid(),
  consultation_id         uuid references community_consultations(id) on delete cascade,
  department              text not null,  -- '企画部関係'
  opinion_number          integer,        -- 部署内通し番号
  text                    text not null,
  is_cross_department     boolean default false,  -- 網掛け意見
  opinion_type            text,           -- 'demand' | 'proposal' | 'complaint' | 'question'
  ai_summary              text,           -- AI生成の1文要約
  created_at              timestamptz default now()
);

-- AIタグ（多対多）
create table community_consultation_opinion_tags (
  opinion_id  uuid references community_consultation_opinions(id) on delete cascade,
  tag         text not null,
  primary key (opinion_id, tag)
);
```

### 3-2. タグの候補分類（AI付与）

```
交通・移動     防災・防犯     子育て・教育
施設・インフラ  産業・雇用     コミュニティ・振興会
財政・予算     行政サービス   情報発信
議会・議員     空き家        人口減少・移住
芸備線        高齢者・介護   農業・林業
```

## 4. ページ設計方針

### 設計原則：ナラティブ先行・データは後段

400件を並べても市民には伝わらない。
**「何が多く語られたか」を読まずに理解できる** ことを最優先とする。

```
ファーストビューで解決する問い：「今年、市民は何を心配していたの？」
スクロールすることで解決する問い：「自分の地域は何を言っていたの？」
さらに深く読みたい人向け：全件フィルタ一覧
```

#### ② 今年の安芸高田市の課題（メインコンテンツ）

**「テーマの分類」ではなく「課題の言語化」をトップに出す。**
訪問者が最初に見て「あ、今の安芸高田はこういう問題を抱えてるんだ」と即理解できる構成。

AIが400件の意見全体を読んで **「この市が抱える構造的な課題」** を3〜4つに凝縮する。
カード見出しはタグ名（「コミュニティ・振興会」）ではなく **課題文** にする。

```
┌──────────────────────────┐ ┌──────────────────────────┐
│ 地域を支える担い手が       │ │ 車に頼れなくなった時、     │
│ 見つからない               │ │ 移動手段がない             │
│                            │ │                            │
│ 振興会・区長・消防団——     │ │ 免許返納が進む高齢者が     │
│ どの組織も後継者不足。     │ │ 増える中、公共交通が不十分 │
│ 高齢化とともに地域の       │ │ で孤立するリスクが高まって │
│ 自治機能が崩れ始めている。 │ │ いる。                     │
│                            │ │                            │
│ 関連する意見: 52件 →       │ │ 関連する意見: 35件 →       │
└──────────────────────────┘ └──────────────────────────┘

┌──────────────────────────┐ ┌──────────────────────────┐
│ 市役所が使いにくい         │ │ 産業がなく、               │
│                            │ │ 若者が残れない             │
│ 開庁時間が短く、窓口のた   │ │                            │
│ らい回しも多い。働く世代   │ │ 企業誘致が進まず雇用が     │
│ が使えない行政になってい   │ │ 少ない。子育て世代が安定   │
│ るとの声が根強い。         │ │ して暮らせる場がない。     │
│                            │ │                            │
│ 関連する意見: 38件 →       │ │ 関連する意見: 44件 →       │
└──────────────────────────┘ └──────────────────────────┘
```

> **実装メモ**:
> - 課題カードの見出し・本文・関連意見リンクはDBに `ai_issue_cards` JSON として格納（年度単位で1回だけClaude APIで生成）
> - 「関連する意見 N件」のリンクは、タグや部署でフィルタした意見一覧（④）にジャンプする
> - 課題カードの本文は2〜3文に収める。読まれるかどうかは文量に反比例する

## 5. AI処理（seed時に実行）

意見テキストをClaude APIに渡し、以下を生成してDBに格納。

```typescript
// 各意見に対して
const result = await callClaude(`
以下は安芸高田市地域懇談会での住民意見です。

【意見テキスト】
${opinion.text}

以下をJSON形式で出力してください:
{
  "opinion_type": "demand | proposal | complaint | question のいずれか",
  "ai_summary": "30文字以内の1文要約",
  "tags": ["タグ1", "タグ2"]  // 以下から最大3つ選択
  // 交通・移動 / 防災・防犯 / 子育て・教育 / 施設・インフラ / 産業・雇用
  // コミュニティ・振興会 / 財政・予算 / 行政サービス / 情報発信 / 議会・議員
  // 空き家 / 人口減少・移住 / 芸備線 / 高齢者・介護 / 農業・林業
}
`);
```

## 7. 論点・確認事項

| # | 論点 | 選択肢 |
|---|------|--------|
| 1 | **地域別フィルタ** | PDFは部署単位で整理されており意見と会場の対応が不明。表示しないか、「意見本文に地名が含まれるもの」で推測するか |
| 2 | **意見の全文公開** | 個人が特定できる内容は含まれない（原文ベース）ため全文公開でよいと思われるが要確認 |
| 3 | **年度ルーティング** | `/community-consultations/r7` または `/community-consultations/2025` どちらを使うか |
| 4 | **バーグラフのライブラリ** | Recharts（既存使用あり？）or 純CSSバー |
| 5 | **令和6年度以前のデータ** | PDFが入手できれば同じseedスクリプトで追加可能。優先度は？ |
