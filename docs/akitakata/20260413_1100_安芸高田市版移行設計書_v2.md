### 会派データ（factions）

議員名簿より**全16議員が無所属**であることを確認。かつ、議決結果PDFには**個人の賛否が記載されない**ため、**議決結果（可決・否決）のみを記録する方針**とする。

- `faction_stances` テーブルは使用しない（シードデータにも含めない）
- 会派としては「無所属」のみ登録し、賛否機能は実質的に使用しない
- Admin画面で「会派の賛否」欄が表示される場合は非表示を検討する

```typescript
export const factions: FactionInsert[] = [
  {
    name: "muusyozoku",
    display_name: "無所属",
    sort_order: 1,
    is_active: true,
  },
];
```

## 4. 環境変数の設定一覧

`.env.example` を `.env` にコピーして各値を設定してください。

```bash
cp .env.example .env
```

| 変数名 | 用途 | 必須/任意 | 備考 |
|---|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | SupabaseプロジェクトURL | ✅ 必須 | 安芸高田市版専用のSupabaseプロジェクトを作成して設定 |

| `REVALIDATE_SECRET` | Webキャッシュ無効化用シークレットキー | ✅ 必須 | ランダムな文字列を生成して設定 |
| `AI_GATEWAY_API_KEY` | Vercel AI GatewayのAPIキー | ✅ 必須 | AIチャット機能に必要 |
| `NEXT_PUBLIC_WEB_URL` | 公開WebアプリのURL | ✅ 必須 | 例: `https://akitakata.mirai-gikai.example.com` |
| `ADMIN_URL` | AdminサーバーのURL | ✅ 必須 | 例: `https://admin.akitakata.mirai-gikai.example.com` |
| `OPENAI_API_KEY` | OpenAI APIキー（DALL-E画像生成） | ✅ 必須 | 議案サムネイル自動生成に使用 |
